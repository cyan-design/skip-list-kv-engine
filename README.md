# Skip-List KV Engine
C++ 实现跳表的简易键值存储引擎，适合数据结构课程大作业。

## 功能
- 插入 KV
- 根据Key查询Value
- 更新已有Key的值
- 删除指定Key
- 打印底层链表用于调试
- 持久化Dump：将内存中全部KV数据导出保存到文件
- 持久化Load：从dump文件读取数据，恢复跳表内存状态


## 编译运行
```bash
g++ main.cpp skiplist.cpp -o skip_kv.exe
./skip_kv.exe

## 技术亮点
1. 基于跳表实现有序KV存储，O(logN)的增删查时间复杂度，底层原理参考Redis ZSet
2. 分层随机生成节点层级，维护多层索引链表，替代平衡树，实现简单、无锁并发友好
3. 实现持久化落盘，支持内存数据持久化保存与重启加载，贴近真实存储引擎设计思想
4. 工程化拆分头文件与源文件，代码模块化，无第三方库依赖，使用MinGW即可编译
